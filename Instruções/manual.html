Manual de uso

YouTube Clipper

Transforma o link de um vídeo do YouTube em cortes verticais prontos para TikTok, Reels e Shorts — sem interface, direto pelo terminal.

$ python main.py "https://www.youtube.com/watch?v=XXXXXXXX"

O que este programa faz

Você entrega um link do YouTube. O programa devolve, sozinho, vários cortes curtos (30s a 2min), já no formato vertical, com legenda, marca d'água e identificação da conta. Quatro etapas acontecem automaticamente:

  • Baixa o vídeo do YouTube
  • Transcreve a fala, com o tempo exato de cada frase
  • Analisa a transcrição e escolhe os melhores trechos
  • Corta e formata cada trecho, pronto para postar

Instalação (uma única vez)

1Instalar o FFmpeg
# macOS
brew install ffmpeg
# Ubuntu/Debian
sudo apt install ffmpeg
# Windows (com Chocolatey)
choco install ffmpeg
2Criar um ambiente virtual
python -m venv venv
source venv/bin/activate
# Windows: venv\Scripts\activate
3Instalar as dependências
pip install -r requirements.txt

Gerando seu primeiro corte

Com tudo instalado, rode o comando passando o link do vídeo entre aspas:

python main.py "https://www.youtube.com/watch?v=XXXXXXXX"

O que acontece no terminal, na ordem:

============================================================
PIPELINE DE CORTES VIRAIS
============================================================
[INFO] Saída deste vídeo: clipes/como-crescer-no-tiktok-em-2026/
# ... baixa, transcreve e analisa o vídeo (pode levar alguns minutos)
============================================================
CONCLUÍDO: 6 clipes gerados a partir de 'Como crescer no TikTok em 2026'
Tudo salvo em: clipes/como-crescer-no-tiktok-em-2026/
============================================================
Dica: vídeos longos (podcasts de 1h+) demoram mais. Use --rapido para acelerar bastante.

Onde encontrar os resultados

clipes/
`-- como-crescer-no-tiktok-em-2026/
|-- 01_o-erro-que-90-das-pessoas-cometem.mp4
|-- 02_a-tecnica-que-mudou-tudo.mp4
|-- transcricao.txt
`-- relatorio_cortes.json
  • Os .mp4 — vídeos cortados, numerados, prontos para postar
  • transcricao.txt — transcrição completa, útil para conferir o que foi dito
  • relatorio_cortes.json — horário, gancho, motivo da escolha e legenda sugerida de cada corte

Exemplos práticos

Podcast longo, priorizando velocidade
python main.py "https://youtu.be/XXXXXXXX" --rapido --qtd-cortes 8
Layout com fundo desfocado, sem legenda
python main.py "https://youtu.be/XXXXXXXX" --layout blur --sem-legenda
Conta e marca d'água personalizadas
python main.py "https://youtu.be/XXXXXXXX" --handle @meucanal --sem-marca-dagua

Problemas comuns

"ffmpeg: comando não encontrado" — repita a instalação do FFmpeg e reinicie o terminal.

"[AVISO] Nenhum corte válido foi identificado" — confira o transcricao.txt gerado; vídeos muito musicais ou editados tendem a funcionar pior.

Processamento lento — use --rapido e considere --modelo-whisper base.
